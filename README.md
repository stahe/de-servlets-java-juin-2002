# Java Servlet – Juni 2002

🔗 Online-Kurs: https://stahe.github.io/de-servlets-java-juin-2002/

## Einleitung

Das vorliegende Dokument ist ein **Kursskript** zum Thema Webprogrammierung in Java (Servlets, J2EE-Umgebung).

Es handelt sich nicht um einen vollständigen Kurs. Einige Themen erfordern die Anleitung eines Dozenten, und verschiedene wichtige Themen werden nicht behandelt.

Das Hauptziel besteht darin, den Studierenden die notwendigen Werkzeuge an die Hand zu geben, um selbstständig an den Grundlagen der Webentwicklung in Java zu arbeiten.

## Literaturhinweise

Die wichtigsten Nachschlagewerke sind:

1. *J2EE Programming* – Wrox (vertrieben von Eyrolles)
2. *Java Server Pages* (Fields, Kolb) – Eyrolles
3. *Java Servlet Programming* (Hunter) – O'Reilly

Ein Großteil des Inhalts basiert auf dem ersten Buch, das wesentlich umfassender ist als diese Ressource.

## Zusätzliche, nicht behandelte Themen

Dieses Dokument könnte durch die folgenden Themen ergänzt werden:

- XML-Programmierung
- JSP-Tags
- EJB (Enterprise Java Beans)
